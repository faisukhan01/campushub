# Contributing to campushub

Thanks for your interest in contributing! 🎉

## Ways to help
- 🐞 **Report bugs** — open an [issue](https://github.com/faisukhan01/campushub/issues) with steps to reproduce
- 💡 **Suggest features** — describe the problem you're trying to solve
- 🔧 **Open pull requests** — small, focused PRs are easiest to review

## Getting started
1. Fork & clone the repository
2. Install dependencies for your environment
3. Create a branch: `git checkout -b feat/my-change`
4. Make your change and test it locally
5. Open a pull request with a clear description

## Style
- Keep changes consistent with the existing codebase
- Write descriptive commit messages
- Update documentation when behavior changes

> CampusHub is a full-stack campus platform — keep migrations and seed data backward-compatible when touching the database schema.
